# Claude Card Maker

[立即体验 Claude Card Maker](https://claude-card-maker.vercel.app) · [GitHub Pages](https://abyr1206.github.io/claude-card-maker/)

在@hugh282003老师的Anthropic插图网页基础上把8种底色扩展到了23种底色，同时每种颜色增加21阶的深浅可以选，也支持自定义。也把插图从78款扩展到148款，每款都支持更换不同底色跟文字，画幅维持三种大小，有各种字体可选。欢迎大家来体验优化的扩展版！也请多多支持老师的原版。

## 使用方式

直接用浏览器打开 `index.html`，或访问上方在线链接。部分字体通过在线字体服务加载。
